# CTFd 与 django-helpdesk 全流程 Accuracy、Precision、Recall、F1（统一口径 v3）

用途与形成方式采用同一规则：以完整参考已定函数集评分，每个类别单独判断“属于该类/不属于该类”，不先筛选已识别的入口。
CTFd N=805（扫描 847，参考 unknown 42），django-helpdesk N=421（扫描 425，参考 unknown 4，包含 16 个迁移函数）。
参考为 AI 辅助静态标注，无独立人工逐点复核。原始标签、分数和历史评测不修改，不调用模型。

## 统一定义

- TP：参考属于该类，模型既判为入口，又正确选中该用途/形成方式。
- FP：参考不属于该类，模型却判为该类入口。
- FN（未恢复正例）：参考属于该类，但入口漏检、类别错误或模型未决。原始 unknown 仍单独保留。
- TN：参考不属于该类，模型明确判为非该类。模型 unknown 不当作 TN。
- Accuracy=(TP+TN)/N；P=TP/(TP+FP)；R=TP/该类参考入口总数；F1=2TP/(2TP+FP+未恢复正例)。
- 每类 Accuracy 包含其他类别和普通非入口的 TN，类别很少时容易很高，因此需结合 R/F1。
- 用途按参考主用途评分；形成方式是多选，各标签分别评分，支持数允许重叠。
- 模型回答 none 表示未选择任何用途；unknown 表示未决。保留原始矛盾，不修正回答。
