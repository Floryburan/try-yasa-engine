# CTFd 与 django-helpdesk Jev 结果汇总

模型均为 `jev-1.14.0`（别名 `jev-latest`）。以下主表为入口识别任务，采用已有 AI 辅助静态参考，无独立人工复核。
CTFd 为 847 个业务函数；django-helpdesk 为 425 个应用范围函数，包含 16 个迁移函数。参考 unknown 排除。
准确率按所有参考已定函数计算，模型 unknown 留在分母；召回率覆盖所有参考正例。分类表仅在正确识别的入口上计算：CTFd 253 个、django-helpdesk 92 个。

## 分类汇总及端到端差异

| 分类指标 | CTFd | django-helpdesk |
|---|---:|---:|
| 用途分类准确率 | 95.65% | 78.26% |
| 全部形成方式标签一致率 | 0.40% | 6.52% |
| 标签 micro Precision | 46.70% | 57.26% |
| 标签 micro Recall | 93.94% | 93.06% |
| 标签 micro F1 | 62.38% | 70.90% |
| 标签端到端 micro F1 | 50.44% | 40.06% |

用途准确率和标签完全一致率都只针对已正确识别的入口；端到端标签 F1 同时计入入口漏检造成的标签缺失。
标签完全一致要求所有标签都对且没有多选/未决标签，因此单独 decorator 表现好不代表全部标签一致率高。
django-helpdesk 的接口实现在这 92 个 TP 中没有参考正例，但模型多选了 17 次，因此该行 P=0、R 无分母；不表示整个仓库没有接口实现入口。
