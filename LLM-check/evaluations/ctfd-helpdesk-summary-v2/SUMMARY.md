# CTFd 与 django-helpdesk 全流程指标汇总（更正口径 v2）

本版将用途和形成方式的主表统一改为全流程评测：分母包括完整参考集的该类入口，入口漏检和标签漏选均不能从分母中排除。
所有原始标注及预测保持不变，只修正汇总口径。原 v1 标签表为条件分类评测，仅适合分析“入口已找对后”的分类质量。
AI 辅助静态参考尚无独立人工复核；参考 unknown 排除。CTFd 847 个函数中评分 805 个；django-helpdesk 425 个函数中评分 421 个，包含 16 个迁移函数。

## 三种召回率的区别

- 该类入口检出召回率 = 正确识别为入口的该类函数数 / 参考集中该类入口总数。
- 全流程标签召回率 = 既识别为入口、又正确选中该标签的函数数 / 参考集中该标签入口总数。
- 条件标签召回率 = 正确选中标签的函数数 / 已正确识别入口中参考具有该标签的函数数。最后这一项不是全仓检出效果。

例：CTFd 继承型入口共 201 个，识别为入口 162 个，选对 inheritance 标签 146 个。三种召回依次为 80.60%、72.64%、90.12%。
